# Travel_Designer
# Проект: Travel Designer_рейтинг горнолыжных курортов

## Описание проекта

**Задача:** понять, какие горнолыжные курорты стоит первыми добавить в каталог.

**Проблема:** прямой сопоставимой статистики посещаемости по каждому курорту в открытом доступе нет. В проекте собрано несколько источников и построен воспроизводимый составной рейтинг.

**Ключевой принцип:** главный результат работы - не красивая цифра сама по себе, а воспроизводимый расчёт. Для каждого курорта видно, из каких данных он получен, какие допущения использованы и насколько надёжны исходные данные.

## Структура итоговой витрины

Каждому курорту соответствует одна строка со следующими данными:

- **Исходные показатели:** снег, температура, осадки, солнце, инфраструктура (еда, проживание).
- **Баллы по каждому показателю.**
- **Пять укрупнённых компонентов:** `food`, `lodging`, `precipitation`, `sunshine`, `temperature`.
- **Итоговый индекс.**
- **Место в рейтинге.**
- **Оценка уверенности в данных.**

## Стек технологий

- Jupyter Notebook, Python (pandas, numpy), SQL, Yandex DataLens.

## Основа реализации

За основу взят код куратора в Jupyter Notebook. Автором внесены некоторые дополнения: добавлены дополнительные проверки целостности и корректности данных, внесены изменения в существующие текстовые ячейки и добавлены новые.
